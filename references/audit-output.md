# Audit Output

## Checks Within The Requested Scope

Check distinct dimensions when applicable: argument and qualifier fidelity,
paragraph function and information allocation, medical-English realization,
and accidental inclusion of editing instructions as prose. Passing the outline
does not establish language quality; grammatical sentences do not establish
the right paragraph function. Report concrete findings, not a mandatory matrix
for every passage.

An explicitly language-only or grammar-only review does not reopen evidence,
overall contribution, or confirmed adjacent sections. Apply the smallest checks
needed for the requested audit and retain the minimal-patch rules below.

## Finding Format

For internal review, use compact anchored findings:

| Field | Meaning |
|---|---|
| section/location | where the problem appears |
| severity | high, medium, or low |
| source anchor | shortest sufficient phrase, sentence, table cell, or figure node |
| problem | what is wrong |
| risk | why it matters |
| disposition | direct revision, targeted verification, or mixed |
| revision direction | what to change if directly revisable |
| verification question | what evidence must be checked |

## Severity

- High: likely affects scientific accuracy, clinical interpretation, or journal
  acceptance.
- Medium: affects logic, evidence calibration, figure/table alignment, or
  substantial clarity.
- Low: local wording, repetition, formatting-adjacent clarity, or non-blocking
  polish.

Do not impose an arbitrary finding cap when the user requests an audit. Do not
inflate minor style preferences into scientific issues.

## Minimal Post-Selection Audit

Use this format only when the author explicitly authorizes audit of selected or
assembled text:

| Field | Meaning |
|---|---|
| anchor | Shortest exact phrase locating the issue |
| issue type | Meaning, qualifier, terminology, abbreviation, scientific action, claim strength, citation attachment, assembly, or grammar |
| classification | Necessary correction or optional idiomatic/style suggestion |
| risk | Concrete consequence of leaving or making the change |
| smallest patch | Minimal local replacement, insertion, or deletion |
| author confirmation | Whether the exact text must be changed with author acceptance |

End with an explicit statement that no whole-paragraph rewrite was performed.
When no necessary correction exists, say so and do not manufacture optional
style work. Never apply a proposed patch before author acceptance when it would
change an author-selected exact text.
