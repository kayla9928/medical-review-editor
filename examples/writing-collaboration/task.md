# Demonstration Task

## 可复用任务请求

```text
使用 $medical-review-editor，根据 inputs.md 中的合成资料与已确认作者意图，
为一篇医学叙述性综述起草一个完整英文段落。

按“综合观察、研究依据、研究意义、下一步问题”的顺序组织。
仅使用提供的资料，不进行外部检索，不补充真实文献或临床事实。

保留研究对象、设计、人数、测量时间、调整条件和关联方向，
将 [S1]、[S2] 分别放在对应研究描述之后。
使用自然的美式学术英语，首次出现时定义 FRS。
区分观察性关联与待验证的预测价值。

输出一段完整英文及简短中文说明，供作者确认。
仅使用 medical-review-editor 完成本次写作。
```

## 实际协作过程

- 用户选择“小段落、完整闭环”的写作协作案例。
- 助手提出合成资料、作者意图和论证安排；用户回复“确认”。
- 助手据此交付一份英文第一稿及中文说明。
- 用户回复“确定”，确认该稿；最终文本见 result.md。
- 没有发生文字修改或第二稿；未制造负面反馈或虚构返工过程。

这是同一对话中按已读取 Skill 规则完成的写作，不声称为新会话隐式触发、
独立安装或第二模型盲测。
